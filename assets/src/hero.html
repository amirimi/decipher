Goal

A LiCode link shared in Slack, LinkedIn, X, WhatsApp, iMessage or Discord unfurls into a card with the LiCode mark, a title and one line of description. A link to a case or a track shows that case's question or that track's destination, so a shared challenge reads as a challenge.

Sequence

Someone pastes a LiCode link into a chat or a post. That platform's crawler fetches the page without running JavaScript and reads the Open Graph and Twitter card tags in the HTML <head>. It then downloads the image the tags name and caches the card, usually for days.

The server writes those tags into index.html when it serves any page. It looks the requested path up in one function, preview_for, which returns the case, track or site card.
