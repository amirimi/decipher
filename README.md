# decipher design sources

HTML sources for the PNG images on `main`.

| Source | Renders |
|---|---|
| `src/banner.html` | `assets/banner-light.png`, `assets/banner-dark.png` |
| `src/hero.html` | `assets/hero-sections-light.png`, `assets/hero-sections-dark.png` |
| `src/icon.html` | `.claude-plugin/icon.png` |
| `src/social-preview.html` | `assets/social-preview.png` |

The plugin directory accepts only Markdown, text, JSON, YAML, and images from unverified publishers, so these files live off `main`.
